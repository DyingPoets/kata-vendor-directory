# Vendor Directory — UI Sketch Description

## Main List View
- Search bar at top (searches name, category, contact name)
- Filter bar: Category dropdown, Status toggle (Active/Inactive)
- Table: Vendor Name | Category | Primary Contact | Phone | Last Updated | Actions
- Pagination: 25 per page
- "Add Vendor" button (admin only)

## Vendor Detail View
- Header: Vendor name, category badge, active/inactive toggle (admin only)
- Contacts section: list of contacts with name, title, email, phone
  - "Add Contact" button (admin only)
- Notes section: free text (admin only)
- Metadata: Created by, Created date, Last modified by, Last modified date

## Add/Edit Vendor Form
- Vendor Name (required)
- Category (dropdown, required)
- Status: Active / Inactive
- Primary Contact: name, title, email, phone
- Notes (optional)
